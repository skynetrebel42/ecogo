> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** EcoGo runs at a public HTTPS address (GitHub Pages), built from a public GitHub repo. Its history carries no
personal email, and the app no longer writes anything to the database.

**Architecture:**
- A GitHub Actions workflow tests, builds and deploys `dist/` to GitHub Pages on every push to `main`.
- Vite builds with a relative base (`./`), so the same bundle works at `/ecogo/` and locally. The USDA key comes from a
  repository secret at build time.
- Scans are no longer saved, and the database's anonymous insert permission is removed, which closes S-04.

**Tech Stack:** Vite 6, GitHub Actions (`actions/checkout@v4`, `actions/setup-node@v4`,
`actions/upload-pages-artifact@v3`, `actions/deploy-pages@v4`), Node 24, the Supabase MCP for one migration, and
`git filter-branch` (ships with Git for Windows).

**Spec:** there is no separate spec. The owner's decisions (2026-09-29, from multiple-choice questions) are below and
are the requirements. Background: `PROJECT_HANDOFF.md` ("Owner goals": deployed website, free hosting, public GitHub
repo) and `KNOWN_ISSUES.md` roadmap step 5.

- [ ] **Step 5: Remap the commit ids cited in docs.** Write `$SCRATCH/remap-ids.mjs` with the Write tool:
  ```js
  // Replace old commit ids (7–40 hex chars, containing a letter) in tracked *.md files with the rewritten ids.
  import { readFileSync, writeFileSync } from "node:fs";
  import { execSync } from "node:child_process";
  const [oldFile, newFile] = process.argv.slice(2);
  const oldIds = readFileSync(oldFile, "utf8").trim().split(/\r?\n/);
  const newIds = readFileSync(newFile, "utf8").trim().split(/\r?\n/);
  if (oldIds.length !== newIds.length) throw new Error("id lists differ in length");
  const files = execSync("git ls-files *.md", { encoding: "utf8" }).trim().split(/\r?\n/);
  let replaced = 0;
  for (const file of files) {
    const text = readFileSync(file, "utf8");
    const next = text.replace(/\b[0-9a-f]{7,40}\b/g, (id) => {
      if (!/[a-f]/.test(id)) return id; // plain numbers (e.g. USDA fdcIds) are not commit ids
      const i = oldIds.findIndex((h) => h.startsWith(id));
      if (i === -1) return id;
      replaced++;
      return newIds[i].slice(0, id.length);
    });
    if (next !== text) writeFileSync(file, next);
  }
  console.log(`replaced ${replaced} commit ids`);
  ```
  Run: `node "$SCRATCH/remap-ids.mjs" "$SCRATCH/old-ids.txt" "$SCRATCH/new-ids.txt"`. Expected: `replaced N commit ids`
  with N > 0. Spot-check that `git show --stat <new id of the baseline cited in PROJECT_HANDOFF.md>` is "Baseline:
  untouched Figma Make export".

  ```yaml
  name: Deploy to GitHub Pages

  on:

      branches: [main]
    workflow_dispatch:

  permissions:
    contents: read
    pages: write
    id-token: write

  concurrency:
    group: pages
    cancel-in-progress: true

  jobs:
    build:
      runs-on: ubuntu-latest
      steps:
        - uses: actions/checkout@v4
        - uses: actions/setup-node@v4
          with:
            node-version: 24
            cache: npm
        - run: npm ci
        - run: npm test
        - name: Check the USDA key secret
          env:
            VITE_FDC_API_KEY: ${{ secrets.VITE_FDC_API_KEY }}
          run: test -n "$VITE_FDC_API_KEY" || { echo "::error::Add the VITE_FDC_API_KEY repository secret"; exit 1; }
        - run: npm run build
          env:
            VITE_FDC_API_KEY: ${{ secrets.VITE_FDC_API_KEY }}
        - uses: actions/upload-pages-artifact@v3
          with:
            path: dist

    deploy:
      needs: build
      runs-on: ubuntu-latest
      environment:
        name: github-pages
        url: ${{ steps.deployment.outputs.page_url }}
      steps:
        - id: deployment
          uses: actions/deploy-pages@v4
  ```
